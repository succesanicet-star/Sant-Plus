# 🏥 Santé Plus Niger-Gaya — Site Vitrine Médical Professionnel

Ce projet est un site vitrine moderne, épuré et entièrement responsive conçu pour la clinique **Santé Plus Niger-Gaya**. Il a été développé avec une approche rigoureuse pour répondre aux exigences esthétiques et fonctionnelles des interfaces du secteur de la santé.

L'objectif de ce projet est de démontrer ma double expertise en **Développement Web** et en **Soins Cliniques**, en proposant une expérience utilisateur (UX) fluide, rassurante et optimisée pour la conversion de patients.

---

## 🚀 Fonctionnalités Clés

*   **Design Médical Premium :** Utilisation d'une palette de couleurs stratégique (Bleu confiance, Vert soin et Blanc épuré) respectant les standards visuels du milieu de la santé.
*   **Navigation Fluide & Responsive :** Intégration mobile-first avec Bootstrap 5 pour garantir une lisibilité parfaite sur smartphones, tablettes et ordinateurs.
*   **Typographie Ultra-Lisible :** Utilisation de la police *Inter* (Google Fonts) pour assurer un confort visuel optimal, essentiel pour un public recherchant des informations médicales.
*   **Système d'Action Anti-Blocage (WhatsApp Direct) :** Configuration d'un lien d'urgence et de prise de rendez-vous sécurisé qui s'ouvre instantanément sans déclencher les filtres anti-popups des navigateurs récents.
*   **Architecture Sémantique :** Code HTML5 propre et structuré pour un référencement naturel (SEO) optimal des services de la clinique.

---

## 🛠️ Technologies Utilisées

*   **HTML5 & CSS3** (Architecture sémantique et variables CSS personnalisées)
*   **Bootstrap 5.3.2** (Framework CSS pour la grille responsive et les composants)
*   **FontAwesome 6.4.2** (Icônes vectorielles professionnelles)
*   **Google Fonts** (Typographie de haute qualité)

---

## 📂 Installation et Déploiement Local

Pour lancer ce projet sur votre machine locale, aucune configuration complexe n'est requise :

1. Clonez ce dépôt ou téléchargez les fichiers sources.
2. Ouvrez le fichier `index.html` directement dans votre navigateur ou via l'extension **Live Server** sur Visual Studio Code.
